**1. 用户表单对话框** (`users-action-dialog.tsx`)

**关键改动**:
- 导入 `useTranslation` hook
- 删除顶部的静态 `formSchema` 定义

- 所有 UI 文本替换为 i18n 调用

**代码示例**:
```typescript

  firstName: z.string().min(1, 'First Name is required.'),
  // ...
})

// ✅ 之后 - 动态生成
export function UsersActionDialog() {
  const { t } = useTranslation()

  const formSchema = z.object({
    firstName: z.string().min(1, t('user.validation.firstNameRequired')),
    // ...
  })
}
```

### 2. 语言切换按钮

#### 需求
在导航栏的主题切换按钮旁边添加语言切换按钮,方便用户切换中英文。

#### 创建新组件

**文件**: `frontend/src/components/language-switch.tsx`

**设计特点**:
- 图标: 使用 `Languages` 图标 (更符合语义)
- 样式: 与 `ThemeSwitch` 保持一致
- 交互: 下拉菜单选择语言
- 标签: 简洁的文字标签 (中/EN) 而非国旗emoji

**代码**:
```typescript
export function LanguageSwitch() {
  const { i18n } = useTranslation()

  const languages = [
    { code: 'zh', label: '中文', shortLabel: '中' },
    { code: 'en', label: 'English', shortLabel: 'EN' },
  ]

  return (
    <DropdownMenu modal={false}>
      <DropdownMenuTrigger asChild>
        <Button variant='ghost' size='icon' className='scale-95 rounded-full'>
          <Languages className='size-[1.2rem]' />
        </Button>
      </DropdownMenuTrigger>
      <DropdownMenuContent align='end'>
        {languages.map((lang) => (
          <DropdownMenuItem onClick={() => i18n.changeLanguage(lang.code)}>
            <span className='me-2 text-sm font-medium opacity-70'>
              {lang.shortLabel}
            </span>
            {lang.label}
            <Check size={14} className={cn('ms-auto', currentLang !== lang.code && 'hidden')} />
          </DropdownMenuItem>
        ))}
      </DropdownMenuContent>
    </DropdownMenu>
  )
}
```

## 🎓 关键学习点

### 1. Zod Schema 动态生成与 i18n

**问题**: Zod schema 在文件顶层定义,无法使用 React hook

**解决方案**: 将 schema 移到组件内部

```typescript
// ❌ 错误 - 无法使用 hook
const formSchema = z.object({
  name: z.string().min(1, t('required'))  // t 未定义
})

export function MyForm() {
  const { t } = useTranslation()
  // ...
}

// ✅ 正确 - 在组件内生成
export function MyForm() {
  const { t } = useTranslation()

  const formSchema = z.object({
    name: z.string().min(1, t('required'))  // ✅ t 可用
  })
}
```

**适用场景**:
- 所有需要使用 i18n 的 Zod schema
- 需要访问 React hook 的数据验证
- React Hook Form + Zod + i18next 组合

---

### 2. 工厂函数模式处理 Hook 依赖

**问题**: 静态导出的列定义无法使用 hook

**解决方案**: 改为工厂函数

```typescript
// ❌ 错误 - 静态导出
export const usersColumns: ColumnDef<User>[] = [
  {
    header: () => t('user.username')  // t 未定义
  }
]

// ✅ 正确 - 工厂函数
export function getUsersColumns(): ColumnDef<User>[] {
  const { t } = useTranslation()

  return [
    {
      header: () => t('user.username')  // ✅ t 可用
    }
  ]
}
```

**使用时**:
```typescript
// 在组件内调用
const columns = getUsersColumns()
```

**适用场景**:
- 任何需要使用 hook 的配置对象
- TanStack Table 列定义
- 任何需要动态生成的配置

---

### 3. i18next 参数插值

**用法**:
```typescript
// 翻译文件

```

**适用场景**:
