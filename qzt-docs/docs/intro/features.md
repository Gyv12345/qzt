# 功能总览

企智通将企业管理所需的全部能力整合进同一个产品。下表按模块列出核心功能，每个模块都有独立的文档章节，详细说明数据模型、流程与配置。

## CRM · 客户关系管理

覆盖「市场获客 → 销售转化 → 合同回款」的完整漏斗。

| 子模块 | 核心能力 |
| --- | --- |
| **线索管理** | 线索池、公海、私海；线索分配 / 回收规则；线索转化为客户与联系人 |
| **客户管理** | 客户档案、联系人管理、团队协作（多成员跟单）、客户公海池、客户层级 |
| **商机管理** | 商机看板（Kanban）、阶段流转、赢单 / 输单、商机预期收入统计 |
| **合同管理** | 合同模板（Markdown + 变量占位符）、合同审批、回款计划、回款记录、开票 |
| **产品管理** | 产品分类、规格、价格体系（标准价 / 折扣价）、库存联动 |
| **跟进管理** | 跟进记录（电话 / 拜访 / 微信 / 邮件）、跟进提醒、跟进时间线、AI 生成跟进摘要 |

## 审批中心

企业级工作流引擎，可视化配置、无需写代码。

- **流程设计器**：拖拽式节点编排，支持审批节点、抄送节点、条件分支
- **审批模式**：依次审批、会签（全部同意）、或签（任一同意）、加签、转办
- **流程动作**：同意、拒绝、退回（退回到任意节点）、撤回
- **审批场景**：合同审批、请假、报销、采购单、用印申请等，业务模块直接复用
- **任务中心**：待办、已办、我发起的、抄送我的

## HRM · 人力资源

管理「组织 → 员工 → 考勤 → 薪资」的完整人事链路。

- **部门管理**：树形组织架构，支持多级部门、部门负责人、部门排序
- **岗位管理**：岗位编码、岗位层级、岗位与部门绑定
- **员工管理**：入职、试用期、转正、调岗、离职；完整变更履历；员工与系统用户解耦
- **考勤**：打卡（GPS + WiFi + 人脸）、班次、排班、请假、加班、调休
- **薪资**：薪资结构定义、算薪公式、社保公积金、工资条

## PSI · 进销存

采购、销售、库存一体化。

| 子模块 | 能力 |
| --- | --- |
| **采购** | 采购订单、采购入库、采购退货、供应商对账 |
| **销售** | 销售订单、销售出库、销售退货、客户对账；与 CRM 合同联动 |
| **库存** | 实时库存结余、收发明细、入库 / 出库单、库存盘点、库存预警、安全库存 |
| **供应商** | 供应商档案、供货记录、账期管理 |
| **仓库** | 多仓库、库位、仓库调拨 |

## 财务

面向中小企业的轻量级会计核算。

- **会计科目**：树形科目体系（资产 / 负债 / 权益 / 成本 / 损益），支持辅助核算
- **记账凭证**：凭证录入、凭证审核、凭证过账、反过账；支持摘要模板
- **发票管理**：销项发票、进项发票、发票验真（对接税局）、开票申请审批
- **财务报表**：资产负债表、利润表、现金流量表、总账、明细账、科目余额表

## CMS · 内容管理

支撑官网、博客、帮助中心的 Markdown 内容发布。

- **文章管理**：Markdown 富文本编辑、封面图、摘要、SEO（title / keywords / description）
- **分类管理**：多级分类，分类与文章一对多
- **单页管理**：独立页面（关于我们、联系我们），不走列表
- **标签管理**：文章标签、热门标签

## AI 业务系统

全部业务功能通过 MCP 协议向 AI 开放，让 AI 真正进入业务执行层，而非停留在聊天。

- **全功能 MCP 开放**：14 个工具集、333 个工具，覆盖 CRM / 审批 / OA / HRM / 进销存 / 财务等全部模块的查询与写入
- **主流客户端接入**：Claude Desktop、Cursor、Cline、Continue 等连上即可用自然语言操作系统
- **密钥 + 权限双控**：API Key 绑定真实用户，可按工具集裁剪开放范围，操作级权限与人工操作共享同一套 Casbin 策略

## 系统管理

保障平台安全、稳定、可运维的基础设施。

- **用户管理**：账号、密码策略、账号锁定、账号与员工绑定
- **角色管理**：角色 → 菜单 → API → 权限码，支持数据权限范围
- **菜单管理**：动态菜单，驱动前端路由
- **字典管理**：业务下拉项统一维护（客户来源、行业、学历等）
- **参数配置**：站点信息、存储配置、登录配置等
- **操作日志**：所有写操作自动记录，含请求体、响应体、操作人、IP
- **登录日志**：登录成功 / 失败记录、登录设备、地理位置
- **业务编号**：合同号、客户号、采购单号等规则配置（前缀 + 日期 + 流水）
- **数据重置**：按模块清空业务数据（仅超管可用，用于演示 / 测试环境重置）

## OA · 办公自动化

日常办公协同的全功能套件。

- **费用报销**：报销单、费用明细、发票上传、审批 + 打款标记
- **出差申请**：目的地、预算、审批，关联差旅报销
- **借款 / 备用金**：借款单、部分还款、还款状态追踪
- **工作日志**：日报 / 周报 / 月报，今日完成 + 明日计划
- **日程安排**：日历视图、事件提醒（5 分钟 / 1 小时 / 1 天）
- **会议室预订**：会议室管理、冲突检测、审批占用
- **公告管理**：通知 / 公告发布、已读统计、首页展示
- **站内消息**：SSE 实时推送、审批通知、待办提醒
- **自定义表单**：JSON Schema 字段配置、审批关联
- 详见 [OA 办公自动化](../modules/oa)

## 项目管理

轻量级项目协作，与 CRM 打通交付链路。

- **项目立项**：关联客户与合同、项目经理 + 团队成员
- **任务跟踪**：看板状态（待办 / 进行中 / 已完成）、优先级、截止日期
- **进度管理**：手动更新或按任务完成率计算
- 详见 [项目管理](../modules/project)

## 企业网盘

文件存储与管理，三种权限范围。

- **个人空间**：仅本人可见
- **部门空间**：同部门成员可见
- **公共空间**：全员可见
- 支持文件夹树、重命名 / 移动、回收站、空间用量统计
- 详见 [企业网盘](../modules/cloud)

## 知识库

团队文档协作平台。

- **分类树**：多级分类组织文档
- **富文本编辑**：HTML 图文混排
- **实时协同**：WebSocket 多人同时编辑
- **版本历史**：自动快照、一键回滚
- 详见 [知识库](../modules/kb)

## 定时任务

数据库驱动的 Cron 调度。

- **6 段式 Cron**：秒级精度
- **动态管理**：后台增删改，自动重载调度器
- **手动触发**：即时执行一次
- **执行日志**：状态、耗时、异常堆栈
- 详见 [定时任务](../modules/enterprise)

## 公共服务

跨模块共享基础设施。

- **文件存储**：双桶模型（公共桶 CDN 直链 / 私有桶签名下载）
- **附件管理**：业务对象与文件的多态关联
- **BI 仪表盘**：跨模块数据聚合（CRM / HRM / Finance / PSI 分析）
- 详见 [公共服务](../modules/api)

## MCP 协议

企智通实现了 **Model Context Protocol** 服务端，全部业务功能以标准 MCP 工具开放，允许 Claude Desktop、Cursor、Continue 等 AI 工具直接读写系统数据。

- 14 个工具集、333 个工具：查客户、写跟进、提报销、审单据、盘库存……
- API Key 级工具集裁剪 + Casbin 操作级鉴权，默认拒绝未授权调用
- 详见 [AI 业务系统](../modules/ai)
