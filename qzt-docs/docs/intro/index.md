# 企智通 · 一站式企业管理平台

> 软件免费 · 一次部署 · 数据私有 · AI 原生

企智通（QZT）是一款面向中小企业的**全功能企业管理平台**，将 CRM 客户关系管理、审批流程中心、PSI 进销存、财务会计、HRM 人力资源、CMS 内容管理、AI 智能助手与系统管理整合在同一个产品中，覆盖企业从市场获客、销售转化、合同回款到采购、库存、财务、人事的全链路业务。

## 企智通是什么

企智通不是某一个垂直 SaaS，而是一套**可私有化部署、可二次开发**的一体化业务操作系统。它把过去需要采购 5~8 个软件才能拼齐的能力，收敛成一个工程：

- **CRM**：线索 → 客户 → 商机 → 合同 → 回款 → 产品 → 跟进的完整销售漏斗
- **审批中心**：可视化流程设计器，支持拖拽节点、条件分支、会签 / 加签 / 退回
- **HRM**：组织架构、员工全生命周期、考勤、薪资
- **PSI 进销存**：采购、销售、库存、供应商、仓库
- **财务**：会计科目、记账凭证、发票、财务报表
- **CMS**：Markdown 富文本内容管理，支撑官网 / 知识库
- **AI 助手**：回访话术、跟进记录、日报周报自动生成，Agent 可配置 prompt
- **MCP 协议**：支持 Claude / Cursor 等 AI 工具直接调用系统功能

## 适合什么企业

- **中小企业（10 ~ 500 人）**：希望用一套系统替代多个 SaaS，降低授权与集成成本
- **数据敏感型企业**：金融、医疗、政务、制造等需要数据完全自主可控的场景
- **有定制需求的企业**：希望基于开源代码二次开发，构建自有品牌的管理系统
- **多业态集团**：需要 CRM + 进销存 + 财务一体化，但又不希望数据上云

## 核心价值

| 价值 | 说明 |
| --- | --- |
| **软件免费** | 开源协议，源代码可获取，无按人头收费的授权成本 |
| **一次部署** | 单一二进制后端 + 静态前端，一台服务器即可承载全部业务 |
| **数据私有** | 全部数据存储在自有服务器 / 自有数据库，不经过任何第三方云 |
| **AI 原生** | 内置 AI 助手与 MCP 协议，让 AI 真正成为业务执行层而非聊天玩具 |
| **模块化** | 每个业务模块独立，可按需启用，互不耦合 |

## 技术架构概述

企智通采用**前后端分离**架构，后端为唯一数据源，前端有三套消费方：

- **后端 `qzt-go-server`**：Go 1.25 + Gin + GORM，单体但模块化设计，提供统一 RESTful API
- **管理后台 `admin`**：React 19 + TypeScript + antd 5 + ProComponents，面向运营 / 管理人员
- **内容站点 `cms`**：Next.js 15 + React 19 + Tailwind CSS，面向公众访问（官网 / 博客）
- **移动端 `mobile`**：React 19 + Vite 7 + antd-mobile，面向外勤 / 移动办公

基础设施层依赖 MySQL（主存储）、Redis（缓存 / 会话）、Aliyun OSS 或本地存储（文件），可选 Docker / nginx / pm2 / systemd 部署，Let's Encrypt 自动签发 HTTPS 证书。

```
┌──────────────────────────────────────────────────────────┐
│                      客户端访问层                          │
│  admin (React)      cms (Next.js)      mobile (React)     │
└────────────────┬─────────────┬──────────────┬────────────┘
                 │             │              │
                 ▼             ▼              ▼
┌──────────────────────────────────────────────────────────┐
│              qzt-go-server  (Go 单体后端)                 │
│   Gin · GORM · Casbin RBAC · JWT · 模块化路由             │
└──────┬───────────────┬──────────────────┬────────────────┘
       │               │                  │
       ▼               ▼                  ▼
   MySQL          Redis             OSS / 本地存储
   (业务数据)      (缓存/会话)        (文件资源)
```

## 部署方式

企智通支持多种部署形态，详见[部署章节](../deployment/overview)：

- **单机部署**：一台 2C4G 服务器即可运行全部组件，适合个人 / 小团队试用
- **Docker Compose**：一键编排后端 + 数据库 + 前端，适合标准化交付
- **生产部署**：nginx 反向代理 + 多实例 + 独立 MySQL / Redis，适合中大型企业
