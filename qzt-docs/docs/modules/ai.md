# AI 助手

AI 助手是企智通平台的智能化引擎，基于 OpenAI 兼容接口协议，对接 DeepSeek、通义千问、GPT 等主流大模型，为 CRM 跟进、日报周报、客户回访等高频业务场景提供 AI 赋能。同时通过 MCP（Model Context Protocol）协议开放系统能力，支持外部 AI 助手（如 Claude、ChatGPT）直接调用平台功能，构建「AI + 业务」的深度集成。

## 核心能力

| 能力 | 说明 |
|------|------|
| 多模型支持 | OpenAI 兼容接口，对接 DeepSeek / 通义千问 / GPT |
| 业务 Agent | 回访话术、跟进记录、日报周报等开箱即用 |
| Agent 管理 | 可配置 system prompt / user prompt / 模型 / 温度 |
| MCP 协议 | 向外部 AI 助手开放系统能力调用 |

## 多模型支持

企智通 AI 助手采用 **OpenAI 兼容接口**协议，意味着只要是符合该协议的大模型，均可无缝接入，企业可根据成本、性能、合规要求灵活选型。

### 支持的模型

| 模型 | 提供方 | 特点 |
|------|--------|------|
| **DeepSeek** | 深度求索 | 性价比高，中文表现优秀 |
| **通义千问** | 阿里云 | 国内合规，企业级稳定 |
| **GPT 系列** | OpenAI | 综合能力最强，需海外网络 |
| **其他兼容模型** | 各厂商 | 符合 OpenAI 协议即可接入 |

### 模型配置

在「系统管理 → AI 配置」中设置：

- **API Base URL**：模型服务的接口地址；
- **API Key**：鉴权密钥（加密存储）；
- **默认模型**：如 `deepseek-chat`、`qwen-plus`、`gpt-4o`；
- **请求超时**：防止长时间等待；
- **并发限流**：避免 API 调用超出配额。

## 业务 Agent

系统预置了多个面向真实业务场景的 AI Agent，开箱即用，无需编写 prompt。

### 回访话术 Agent

根据客户/线索的历史信息，自动生成个性化的回访话术，帮助销售人员高效开展客户回访。

**输入**：客户 ID 或线索 ID（系统自动提取客户画像、历史跟进、订单记录）。

**输出**：结构化的回访话术，包括：

- 开场白（结合客户称谓、上次沟通内容）；
- 价值主张（结合客户行业、需求痛点）；
- 异议处理预案（结合客户级别、历史反馈）；
- 促单话术（结合在谈商机、合同进度）；
- 结束语与下次跟进建议。

**应用场景**：老客户续费回访、线索激活回访、商机推进回访。

### 跟进记录 Agent

销售人员在与客户沟通后，往往不愿意手工填写繁琐的跟进记录。本 Agent 解决这一痛点：

**输入**：粘贴与客户的对话内容（微信聊天记录、通话纪要、邮件正文）。

**输出**：结构化的跟进记录，自动提取：

- 沟通时间、沟通方式；
- 客户核心诉求；
- 本次沟通结论；
- 待办事项与负责人；
- 下次跟进时间建议；
- 情感倾向分析（积极 / 中性 / 消极）。

生成的跟进记录可直接保存到 CRM，关联客户与商机，无需手工二次整理。

### 日报周报 Agent

自动汇总销售人员在系统中的工作数据，生成结构化的日报/周报，省去手工总结的时间。

**输入**：时间范围（今日 / 本周 / 本月）、员工 ID。

**自动汇总数据**：

- 新增客户数、新增线索数；
- 跟进次数（按类型统计）；
- 商机推进情况（新增、阶段变更、成交）；
- 合同签订情况；
- 回款金额；
- 待办事项完成率。

**输出**：通顺、专业的日报/周报文本，可直接提交上级或分享团队。

## Agent 管理

除预置 Agent 外，管理员可在「AI 助手 → Agent 管理」中自定义新的 Agent，灵活扩展 AI 能力。

### 可配置项

| 配置项 | 说明 | 示例 |
|--------|------|------|
| **Agent 名称** | 标识用 | 「合同条款审查」 |
| **System Prompt** | 定义 Agent 角色与行为约束 | 「你是一名法务专家，专注于合同条款风险审查...」 |
| **User Prompt 模板** | 用户输入的模板，支持变量 | 「请审查以下合同：`{contractContent}`」 |
| **模型** | 选择使用的具体模型 | deepseek-chat / gpt-4o |
| **温度（Temperature）** | 控制输出随机性，0~2 | 0.2（严谨）/ 0.8（创意） |
| **最大 Tokens** | 输出长度上限 | 2000 |
| **上下文变量** | 注入业务数据 | 客户信息、合同信息、员工信息 |

### 变量注入

User Prompt 模板支持 `${变量}` 注入业务数据，Agent 执行时自动替换：

- `${customerName}`：客户名称；
- `${customerIndustry}`：客户行业；
- `${dealAmount}`：商机金额；
- `{contractContent}`：合同正文；
- `${followUpHistory}`：历史跟进记录。

变量清单与合同模板变量共用一套体系，详见 [CRM 合同模板](./crm#合同模板)。

### 温度参数说明

温度（Temperature）控制模型输出的随机性，是 Agent 调优的关键参数：

| 温度范围 | 特点 | 适用场景 |
|---------|------|---------|
| 0 ~ 0.3 | 输出确定、严谨 | 财务分析、合规审查、数据提取 |
| 0.4 ~ 0.7 | 平衡 | 话术生成、日报撰写 |
| 0.8 ~ 1.2 | 富有创意 | 营销文案、创意方案 |
| > 1.2 | 高度随机 | 头脑风暴（慎用） |

## MCP 协议

MCP（Model Context Protocol）是 Anthropic 提出的开放协议，旨在让 AI 助手能够标准化地调用外部系统的能力。企智通平台实现了 **MCP Server**，向支持 MCP 的外部 AI 助手（如 Claude、ChatGPT、Cursor）开放平台功能。

### 工作原理

```
┌─────────────────┐         MCP 协议         ┌─────────────────┐
│  外部 AI 助手    │ ◀──────────────────────▶ │  企智通 MCP      │
│  Claude/GPT     │     工具调用 / 结果返回     │  Server         │
└─────────────────┘                          └────────┬────────┘
                                                      │
                                                      ▼
                                             ┌─────────────────┐
                                             │  企智通业务系统   │
                                             │  CRM/PSI/HRM    │
                                             └─────────────────┘
```

### 开放的能力

通过 MCP，外部 AI 助手可以调用企智通的以下能力（持续扩展）：

| 能力域 | 可调用操作 |
|--------|----------|
| **CRM** | 查询客户、创建客户、查询合同、创建文章、查询合同模板 |
| **CMS** | 创建文章、查询文章列表、查询站点配置 |
| **存储** | 查询存储配置、测试 OSS 连接、更新存储配置 |
| **企业微信** | 创建企微配置、查询配置列表、启用/禁用 |

:::tip 典型用法
在 Claude Desktop 或 Cursor 中配置企智通的 MCP Server 后，您可以直接对 AI 说：「帮我查一下上周新增的客户」、「把这个客户的合同模板生成一下」，AI 会自动调用企智通的接口完成任务，无需打开后台手工操作。
:::

### 安全与鉴权

- MCP 调用需通过 **API Token** 鉴权，Token 在系统管理中生成；
- 每个 Token 可配置**权限范围**（只读 / 读写 / 仅特定模块）；
- 所有 MCP 调用均记录在操作日志中，便于审计；
- 支持 IP 白名单限制调用来源。
