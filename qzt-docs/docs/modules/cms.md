# CMS 内容管理

CMS（Content Management System）是企智通平台的内容运营模块，用于管理企业官网的文章、分类、单页等内容资源，并提供站点信息（Logo、备案、SEO）的统一配置。模块与 Admin 后台共用同一套站点配置，内容发布后可直接同步到企业官网（你的域名），实现「一处编辑，多处展示」。

## 核心能力

| 能力 | 说明 |
|------|------|
| 文章管理 | Markdown 富文本编辑器 |
| 分类与标签 | 多维度内容组织 |
| 单页管理 | 关于我们、联系我们等独立页面 |
| 站点信息 | Logo、备案、SEO 统一配置 |
| 官网同步 | 内容同步到企业官网 |

## 文章管理

文章是 CMS 的核心内容对象，支持 Markdown 富文本编辑。

### Markdown 富文本编辑器

系统内置功能完善的 Markdown 编辑器，兼顾写作效率与排版表现：

- **Markdown 语法**：支持标题、加粗、斜体、列表、引用、代码块、分隔线等标准语法；
- **表格支持**：Markdown 表格语法，支持对齐方式；
- **图片上传**：粘贴或拖拽图片自动上传至 OSS / 本地存储，返回 URL 插入正文；
- **代码高亮**：支持 Go、JavaScript、Python、Bash 等多种语言的语法高亮；
- **实时预览**：左侧编辑、右侧实时预览，所见即所得；
- **图片摘要**：自动提取正文图片生成图片摘要，用于列表缩略图。

### 文章字段

| 字段 | 说明 |
|------|------|
| 标题 | 文章标题 |
| 正文 | Markdown 内容 |
| 摘要 | 列表展示用，500 字以内 |
| 封面图 | 列表封面（URL） |
| 分类 | 关联文章分类 |
| 标签 | 多标签 |
| 别名（Slug） | URL 友好别名，如 `crm-lifecycle` |
| 作者 | 作者昵称（默认「企智通团队」） |
| 状态 | 草稿 / 已发布 |
| 是否置顶 | 列表置顶 |
| 是否热门 | 标记热门 |
| 排序 | 同级排序值 |
| SEO 关键词 | 搜索引擎优化 |

### 发布流程

```
草稿 ──── 编辑完善 ────▶ 待发布 ──── 审核 ────▶ 已发布
                                  │
                                  ▼
                            发布到官网
```

- 文章默认为「草稿」状态，可反复编辑预览；
- 发布后立即可在官网访问；
- 支持定时发布（配置发布时间，到点自动上线）；
- 已发布文章可随时撤回为草稿。

### URL 别名（Slug）

每篇文章可配置 URL 友好别名，用于 SEO：

- 格式：小写字母、数字、中划线，如 `crm-lifecycle`；
- 访问路径：`/blog/crm-lifecycle`；
- 若不配置，系统自动根据标题或 ID 生成。

## 分类与标签

### 分类

分类是文章的**纵向归属**，采用树形结构：

- 一个文章归属一个分类；
- 分类支持多级（如「产品动态」下有「新功能」「版本更新」）；
- 分类可配置图标、描述、排序；
- 分类页自动聚合该分类下的所有文章。

### 标签

标签是文章的**横向关联**，扁平结构：

- 一篇文章可打多个标签；
- 标签用于相关文章推荐；
- 标签云展示高频标签；
- 点击标签可查看所有相关文章。

:::tip 分类 vs 标签
分类是「归属」，一篇文章只属于一个分类（如「产品动态」）；标签是「特征」，一篇文章可有多个标签（如「AI」「CRM」「新功能」）。两者配合使用，构建多维度的内容导航。
:::

## 单页管理

单页（Single Page）用于管理「关于我们」「联系我们」「服务条款」「隐私政策」等独立静态页面：

- 单页同样使用 Markdown 编辑；
- 单页有固定的 URL（如 `/about`、`/contact`）；
- 单页不进入文章列表，但在导航菜单中展示；
- 单页支持自定义模板布局。

## 站点信息

CMS 模块与系统管理共用一套站点信息配置，修改后官网与后台同步生效。详见 [系统管理 → 站点信息](./system#站点信息)。

核心配置包括：

| 配置 | 用途 |
|------|------|
| 企业名称 | 官网页眉、页脚 |
| Logo | 官网导航栏 Logo |
| Favicon | 浏览器标签图标 |
| 联系方式 | 联系我们页面 |
| ICP 备案 | 页脚备案号（合规要求） |
| 公安备案 | 页脚公安备案号 |
| SEO 关键词 | 官网 meta 标签 |
| 品牌标语 | 官网首屏 Slogan |

## 同步到企业官网

CMS 编辑的内容会自动同步到企业官网（你的域名），实现内容运营闭环：

```
┌──────────────┐   发布文章    ┌──────────────┐
│  Admin 后台   │ ────────────▶ │  CMS 数据库   │
│  CMS 编辑     │               │              │
└──────────────┘               └──────┬───────┘
                                      │
                                      ▼
                               ┌──────────────┐
                               │  企业官网     │
                               │  企智通 │
                               │   .com       │
                               └──────────────┘
```

- 文章发布后，官网博客列表自动更新；
- 站点信息修改后，官网页眉页脚同步刷新；
- 官网采用 Next.js SSR 渲染，保证 SEO 友好；
- 支持官网独立域名与后台域名的分离部署。
