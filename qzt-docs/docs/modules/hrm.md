# HRM 人事管理

HRM（Human Resource Management）是企智通平台的人事管理模块，覆盖**组织架构**、**员工全生命周期**、**考勤管理**与**离职交接**四大核心能力。模块与 CRM、审批中心深度联动，员工入职自动开通账号，离职时一键转移其名下客户、线索、商机、合同等业务数据，确保业务连续性不受人员变动影响。

## 组织架构

组织架构是 HRM 的基础数据，也是权限控制、审批流转、数据范围的数据来源。

### 部门（树形）

部门采用**树形层级**结构，支持任意深度的父子关系，贴合企业的实际组织形式。

- **多级部门**：集团公司 → 分公司 → 事业部 → 部门 → 小组，层级无限制；
- **部门负责人**：每个部门可设置负责人，用于审批流的「部门负责人」类型自动解析；
- **部门排序**：支持自定义排序，前端树形展示按排序呈现；
- **部门停用**：部门可停用而不删除，保留历史数据归属；
- **部门编码**：支持编码字段，便于与外部系统对接。

典型部门树示例：

```
├── 总裁办
├── 销售中心
│   ├── 销售一部
│   ├── 销售二部
│   └── 渠道部
├── 研发中心
│   ├── 产品组
│   ├── 后端组
│   └── 前端组
├── 财务部
└── 人事行政部
```

### 岗位

岗位（Position）是员工在组织中的「角色定位」，与部门正交：

- 一个部门下可设置多个岗位（销售经理、销售总监、售前工程师）；
- 一个员工关联一个部门 + 一个岗位；
- 岗位用于权限分配、薪资定级、审批层级判断；
- 岗位支持层级（如「销售经理」上级是「销售总监」）。

## 员工管理

员工（Employee）是 HRM 的核心对象，承载从入职到离职的完整履历。员工记录与系统登录账号（User）一一关联：员工入职后自动开通账号，离职后自动停用账号。

### 入职

入职流程标准化，支持走审批流（需人事、IT、部门负责人多签）：

- 录入员工基本信息：姓名、性别、身份证、联系方式、紧急联系人；
- 录入工作信息：部门、岗位、职级、入职日期、试用期、直属上级；
- 录入合同信息：合同类型、合同期限、薪资（加密存储）；
- **自动开通账号**：根据岗位自动分配默认角色与权限；
- 自动生成员工编号（如 `EMP20260806001`）。

### 调岗

员工在企业内的岗位、部门变更通过「调岗」操作记录：

- 记录调岗前后：原部门 → 新部门、原岗位 → 新岗位；
- 调岗可走审批流（需原部门负责人、新部门负责人、人事确认）；
- 调岗后自动更新权限范围（数据权限跟随部门变化）；
- 调岗记录进入员工变更履历。

### 离职

离职流程标准化，确保交接清晰、数据完整：

- 发起离职申请（可走审批流）；
- 系统自动列出该员工名下的待办、跟进、客户、线索、商机、合同；
- 通过**离职交接**功能批量转移业务数据（见下文）；
- 离职生效后自动停用登录账号；
- 离职记录归档，保留历史可查。

### 变更履历（自动记录）

系统自动记录员工的所有关键变更，形成完整的职业履历，无需人工维护：

| 履历类型 | 触发动作 | 记录内容 |
|---------|---------|---------|
| 入职 | 创建员工 | 入职日期、部门、岗位 |
| 调岗 | 调岗操作 | 前后部门、前后岗位、生效日期 |
| 晋升 | 职级变更 | 前后职级、生效日期 |
| 转正 | 试用期结束 | 转正日期 |
| 离职 | 离职生效 | 离职日期、离职原因、交接情况 |

变更履历不可编辑、不可删除，可作为人事档案的可靠依据。

## 考勤管理

考勤模块记录员工的出勤、请假、加班情况，并自动汇总生成考勤报表。

### 打卡

- **打卡方式**：支持 PC 端打卡、移动端 GPS 定位打卡、企业微信打卡；
- **班次配置**：可配置固定班次（朝九晚六）、弹性班次、排班制；
- **打卡规则**：迟到、早退、漏卡自动判定；
- **补卡申请**：漏卡可发起补卡申请走审批流。

### 请假

- 请假类型：事假、病假、年假、调休、婚假、产假、丧假等；
- 请假申请自动走审批流（详见 [审批中心](./approval)）；
- **假期余额**：年假、调休有额度管理，请假自动扣减，超额拦截；
- 请假记录计入考勤汇总。

### 加班

- 加班申请走审批流；
- 加班时长可转为调休额度；
- 加班记录计入考勤汇总。

### 考勤汇总

系统按月自动汇总每位员工的考勤数据，生成考勤报表：

| 汇总项 | 说明 |
|--------|------|
| 应出勤天数 | 当月工作日 |
| 实际出勤天数 | 实际打卡天数 |
| 迟到次数 / 时长 | 按规则统计 |
| 早退次数 / 时长 | 按规则统计 |
| 请假天数 | 各类请假明细 |
| 加班时长 | 审批通过的加班时长 |
| 调休余额 | 当前可用调休 |

考勤报表可导出 Excel，作为薪资核算的依据。

## 离职交接

离职交接是 HRM 模块最具业务价值的能力之一。当销售人员离职时，其名下往往积累了大量客户、线索、商机、合同，如果交接不清，将直接造成客户流失和业绩损失。

### 批量转移

系统提供**一键批量转移**功能，将离职员工名下的所有业务数据转交给指定同事：

| 可转移对象 | 说明 |
|-----------|------|
| **客户** | 转移客户负责人，可选择是否同时转移团队成员关系 |
| **线索** | 转移线索负责人 |
| **商机** | 转移商机负责人 |
| **合同** | 转移合同负责人（不影响回款归属） |
| **跟进记录** | 跟进记录随对象转移，保留历史 |

### 交接流程

1. 人事或管理员发起离职交接，选择离职员工与接收人；
2. 系统列出离职员工名下的所有业务数据及数量；
3. 可选择性转移（全部 / 部分 / 按条件筛选）；
4. 确认转移后，业务数据的负责人字段批量更新为接收人；
5. 转移完成生成交接清单，双方签字确认（线上）。

:::tip 数据安全
离职转移是**不可逆**操作，但所有变更都会记录在「变更历史」中，可通过变更历史追溯每一次负责人变更。离职员工的账号在交接完成后自动停用。
:::
