# 邮件服务

邮件服务模块提供 **SMTP 发信**能力，支持 Markdown 正文自动渲染 HTML、附件发送、抄送、连接测试。配置统一在系统参数中维护，各业务模块（如审批通知、报表推送）可通过共享服务调用发信。

:::info 仅发信
当前邮件模块为**纯发信**（Outbound SMTP），不支持收信（IMAP/POP3）。所有配置通过系统参数（`sys_config`）管理，无需独立数据表。
:::

## 配置项

邮件配置在「系统管理 → 参数配置」中维护，支持热更新（无需重启）：

| 参数 Key | 说明 | 示例 |
|----------|------|------|
| `mail.enabled` | 是否启用邮件服务 | `true` |
| `mail.host` | SMTP 服务器地址 | `smtp.qq.com` |
| `mail.port` | SMTP 端口 | `465`（SSL）/ `587`（STARTTLS） |
| `mail.username` | 发信账号 | `noreply@company.com` |
| `mail.password` | 发信密码 / 授权码 | `••••••••` |
| `mail.from` | 发件人邮箱 | `noreply@company.com` |
| `mail.from_name` | 发件人名称 | `企智通系统通知` |
| `mail.encryption` | 加密方式 | `ssl` / `starttls` / `none` |

## 发信功能

### 请求参数

| 字段 | 说明 |
|------|------|
| **收件人 to** | 收件人邮箱列表（数组） |
| **抄送 cc** | 抄送人邮箱列表（可选，数组） |
| **主题 subject** | 邮件主题（支持中文，RFC 2047 编码） |
| **正文 body** | Markdown 格式，发送时自动渲染为 HTML |
| **附件 attachments** | 附件列表（可选） |

### Markdown 渲染

邮件正文支持 **Markdown 语法**，发送前自动渲染为带样式的 HTML：

- 支持标题、列表、表格、加粗、链接、图片等 Markdown 元素
- 渲染后的 HTML 经过 **XSS 过滤**（bluemonday），移除危险标签和属性
- 支持内联 CSS 样式，兼容主流邮件客户端

### 附件处理

附件支持两种来源：

| 来源 | 处理方式 |
|------|---------|
| **公共文件（URL）** | 直接使用 URL 作为附件下载链接 |
| **私有文件（objectKey）** | 后端先签名生成临时下载 URL，再下载后作为附件发送 |

## 连接测试

`POST /mail/test` 接口用于验证 SMTP 配置是否正确：

- 向 `mail.from`（发件人自己）发送一封测试邮件
- 如果配置有误会返回详细的错误信息（如认证失败、连接超时、端口不通等）
- 配置变更后建议先执行测试，确认发信通道正常
