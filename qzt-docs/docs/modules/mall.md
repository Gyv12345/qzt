# 独立商城（mall）

mall 是**免登录的公开垂直商城**后端：商城前台（mall 站点）不需要注册登录即可浏览商品、下单查询，订单自动进入后台进销存体系。商品与订单与 [CRM](/modules/crm)、[PSI 进销存](/modules/psi) 深度打通，是「官网获客 → 商城成交 → 进销存履约」链路的成交端。

## 设计要点

- **商品零维护**：商城商品直接复用 CRM 产品库的上架商品（价格取标准价 `standard_price`），后台维护产品即上架，无需二次录入；
- **免登录**：公开路由 `/mall/public/*` 不鉴权，商城前台直接调用；下单仅留收货人/电话/地址，不建账号体系；
- **下单即履约**：订单创建成功后**自动生成 PSI 销售单**，走标准销售出库流程扣减库存；
- **散客复用**：按收货手机号在商城域内复用客户档案（无则创建 `source=MALL` 的公海客户），避免散客记录膨胀；
- **不暴露成本**：所有公开 DTO 均不含成本价字段。

## 接口清单

### 公开路由（免登录，商城前台专用）

| 接口 | 方法 | 说明 |
|------|------|------|
| `/mall/public/goods` | GET | 上架商品列表（含规格 SKU、全仓库存「有货/无货」参考），一次拉取上限 200 |
| `/mall/public/orders` | POST | 公开下单（收货人 / 电话 / 地址 / 商品明细） |
| `/mall/public/orders/:orderNo` | GET | 按订单号查询订单（买家自助查单） |

### 管理路由（JWT + Casbin）

| 接口 | 方法 | 说明 |
|------|------|------|
| `/mall/orders` | GET | 订单分页列表 |
| `/mall/orders/:id` | GET | 订单详情（含商品明细） |
| `/mall/orders/:id/status` | PUT | 更新订单状态 |
| `/mall/orders/:id/generate-sales-order` | POST | 补生成 PSI 销售单 |

## 商品视图

公开商品视图包含：商品名、编号、分类、单位、标准价、图片、描述、SKU 列表（规格描述、SKU 编号、价格、图片、库存量与是否在库）。库存为全仓汇总值，**仅做「有货/无货」参考，不承诺精确到仓**。

## 下单流程

```
买家在商城前台提交订单
   │
   ▼
校验商品可售 + 数量
   │
   ▼
创建商城订单（价格快照：商品名/规格/单价/金额按下单时刻落库）
   │  订单号：MO + yyyyMMdd + 6 位纳秒尾（数据库唯一索引兜底）
   ▼
散客客户复用（同手机号复用历史客户，否则创建公海客户 source=MALL）
   │
   ▼
自动生成 PSI 销售单（复用 psi SalesService）
   │
   ▼
买家凭订单号 / 手机号自助查单；后台接手确认 → 完成
```

### 订单状态

| 状态 | 说明 |
|------|------|
| 1 待处理 | 下单成功待后台确认 |
| 2 已确认 | 后台已确认（默认已同步生成 PSI 销售单） |
| 3 已完成 | 履约完成 |
| 4 已取消 | 取消 |

:::info 手动补生成销售单
订单创建时自动生成 PSI 销售单；若生成失败（如库存/仓库配置问题），管理端可对订单调用 `POST /mall/orders/:id/generate-sales-order` 补生成，订单记录会回填关联的 PSI 销售单 ID。
:::

## 与其他模块的联动

| 联动模块 | 联动场景 |
|---------|---------|
| [CRM](/modules/crm) | 商品复用 `crm_product`（含 SKU）；散客按手机号沉淀为客户档案 |
| [PSI 进销存](/modules/psi) | 下单自动生成销售单，走标准出库扣减库存 |
| [系统管理](/modules/system) | 公开商城域名（mall 站点）由 nginx 静态托管，见[部署概述](/deployment/overview) |
