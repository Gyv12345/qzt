# 营销获客（marketing）

marketing 模块承接**付费广告渠道的线索接入**：当前支持**巨量引擎（抖音）飞鱼线索**，渠道账号完成 OAuth 授权后，广告投放产生的线索自动、增量同步进 CRM 线索公海，让投放获客与销售跟进无缝衔接。

:::note 智能外呼已下线
模块早期的智能外呼（阿里云 OutboundBot 电话营销）已于 2026-09 因电话营销监管合规要求整体下线，当前能力聚焦在广告线索同步。
:::

## 核心概念

```
抖音广告投放 → 巨量引擎飞鱼线索 → marketing 同步（定时 15 分钟 / 手动）
                                        │
                     token 续期 → 增量拉取 → 三道去重 → 落 CRM 线索公海
                                        │
                              同步日志（已入库 / 重复跳过 / 失败）+ 汇总通知
```

| 对象 | 说明 |
|------|------|
| 渠道账号 `marketing_account` | 一条记录对应一个开放平台应用（AppID/Secret + OAuth 令牌 + 已授权广告主 ID） |
| 线索同步日志 `marketing_lead_log` | 每条外部线索的入库轨迹：外部线索 ID、落库后的 CRM 线索 ID、姓名/手机号、入库状态 |

## 渠道账号管理

| 字段 | 说明 |
|------|------|
| 账号名 / 渠道 | 备注名；渠道当前为 `oceanengine`（巨量引擎） |
| AppID / AppSecret | 开放平台应用凭据，Secret 仅保存不回显 |
| access_token / refresh_token | OAuth 令牌，剩余寿命不足 1 分钟自动续期，均不回显 |
| 广告主 ID | 已授权的广告主账号（逗号分隔） |
| 授权状态 / 启用 | 是否完成授权、是否参与定时同步 |
| 上次同步游标 | 增量拉取的时间游标 |

### 接口清单

| 接口 | 方法 | 说明 |
|------|------|------|
| `/marketing/accounts` | GET / POST | 账号分页列表（密钥脱敏）/ 新增 |
| `/marketing/accounts/:id` | PUT / DELETE | 编辑 / 删除 |
| `/marketing/accounts/:id/authorize-url` | GET | 生成 OAuth 授权链接 |
| `/marketing/accounts/:id/sync` | POST | 手动触发一轮同步 |
| `/marketing/oauth/callback` | GET | OAuth 回调（免鉴权公开路由，state 经 Redis 校验） |
| `/marketing/logs` | GET | 同步日志分页（支持按账号/状态过滤） |
| `/marketing/logs/:id` | GET | 单条日志详情 |

## 线索同步机制

### 增量拉取

- 首次同步（无游标）默认**回看 24 小时**，避免一次拉入历史全量；
- 每轮以账号上的游标时间增量拉取，游标**回拨 5 分钟**容忍巨量侧线索延迟上报，重叠部分由唯一键兜底去重；
- 分页拉取（每页 100 条，上限 50 页），单轮有规模安全上限。

### 三道去重闸门

1. **同步日志唯一键** `(account_id, external_id)`：外部线索 ID 跨轮幂等，重叠窗口重复拉取不二次入库；
2. **CRM 线索手机号精确匹配**：同手机号已有线索则跳过，日志标记「重复跳过」；
3. **自动编号唯一**：线索编号由自动编号服务原子生成，天然不重复。

### 落库规则

新线索直连创建 CRM 线索：来源标记「抖音广告」、**直接入公海**（不设公海池 ID、不指定负责人），由销售在公海领取后跟进；入库后日志回填 CRM 线索 ID，并按批次汇总通知。

### 触发方式

| 方式 | 说明 |
|------|------|
| 定时任务 `marketing.feiyu.pull` | 每 15 分钟遍历「启用且已授权」的账号逐个同步；单账号失败记日志不中断其余账号 |
| 手动触发 | Admin 页面或 `POST /marketing/accounts/:id/sync` 立即执行一轮，返回入库 / 跳过 / 失败统计 |

### 同步日志状态

| 状态 | 说明 |
|------|------|
| 1 已入库 | 线索成功落入 CRM 公海 |
| 2 重复跳过 | 外部 ID 或手机号重复，未重复入库 |
| 3 失败 | 拉取或落库失败，保留原因可排查 |
