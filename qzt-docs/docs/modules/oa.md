# OA 办公自动化

OA（Office Automation）是企智通的日常办公协同中心，覆盖**费用报销、出差借款、工作日志、日程安排、会议室预订、公告发布、站内消息**以及**自定义表单**等场景。所有业务单据均可接入 [审批中心](./approval) 走流程审批，审批通过后自动回写业务状态。

## 业务全景

```
┌──────────────────────────────────────────────────────────────────┐
│                        OA 办公自动化                              │
├──────────┬──────────┬──────────┬──────────┬──────────────────────┤
│  费用    │  出差    │  借款    │  日志    │  日程 / 会议 / 公告   │
│ Expense  │  Trip    │  Loan    │  WorkLog │  Schedule / Meeting  │
├──────────┴──────────┴──────────┴──────────┴──────────────────────┤
│                    自定义表单 FormTemplate                        │
├─────────────────────────────────────────────────────────────────┤
│               站内消息 OaMessage（SSE 实时推送）                  │
└─────────────────────────────────────────────────────────────────┘
```

## 费用报销

费用报销是 OA 中使用频率最高的场景，覆盖差旅、办公、招待、交通、通讯等各类费用。

| 功能 | 说明 |
|------|------|
| **报销单** | 标题、费用明细（多项）、总金额、说明 |
| **费用明细** | 费用类型（差旅/办公/招待/交通/通讯/其他）、金额、日期、说明 |
| **审批流程** | 提交后进入 [审批中心](./approval)，通过后可标记已打款 |
| **打款标记** | 财务确认打款后，状态从「已审批」变为「已打款」 |
| **附件** | 支持上传发票照片、凭证截图（走 [文件存储](../architecture/storage)） |

## 出差申请

出差申请管理员工的外出行程，审批通过后作为考勤和费用报销的依据。

- 字段：标题、目的地、出行方式、预算金额、出差日期（起止）、说明
- 审批通过后自动关联费用报销（差旅费明细可引用出差单）
- 支持审批流程，与 [审批中心](./approval) 联动

## 借款 / 备用金

管理员工向公司借款的场景（差旅借支、备用金、个人借款等）。

| 功能 | 说明 |
|------|------|
| **借款单** | 类型（备用金/差旅借支/个人借款/其他）、金额、说明 |
| **审批流程** | 提交后走审批流 |
| **还款记录** | 支持部分还款，系统自动计算未还金额 |
| **还款状态** | 未还 → 部分已还 → 已还清 |

## 工作日志

工作日志支持日报、周报、月报三种形式，是团队管理和绩效评估的参考依据。

| 类型 | 适用场景 |
|------|---------|
| **日报** | 每日工作内容、完成情况、遇到的问题 |
| **周报** | 本周总结、下周计划 |
| **月报** | 月度工作汇总、里程碑进展 |

日志字段包括：今日完成、明日计划、存在问题。支持按人员、类型、日期范围筛选查看。

## 日程安排

个人日程管理，支持事件提醒。

| 事件类型 | 说明 |
|---------|------|
| **会议** | 内部/外部会议 |
| **任务** | 待办事项 |
| **提醒** | 跟进提醒、到期提醒 |
| **外出** | 外出/拜访 |

- **提醒方式**：无提醒 / 提前 5 分钟 / 15 分钟 / 1 小时 / 1 天
- **日历视图**：支持月历视图查看日程分布
- **状态管理**：待处理 → 已完成 / 已取消

## 会议室预订

会议室资源管理 + 预订审批。

### 会议室管理

- 维护会议室基础信息：名称、容量、设备配置（投影/白板/视频会议等）
- 状态：启用 / 停用 / 维护中
- 仅管理员可管理会议室

### 会议预订

| 功能 | 说明 |
|------|------|
| **预订单** | 选择会议室、主题、组织者、参会人、时间段 |
| **冲突检测** | 同一会议室同一时间段不可重复预订 |
| **审批流程** | 预订需走审批，通过后自动占用会议室 |

## 公告管理

企业内部通知与公告发布。

- **公告类型**：通知（日常事务）、公告（重要事项）
- **发布流程**：草稿 → 发布 → 撤回
- **已读统计**：发布后可查看已读 / 未读人员
- **首页展示**：已发布公告自动出现在工作台首页的公告栏

## 站内消息

站内消息是系统的实时通知中枢，所有模块的事件通知都通过站内消息推送。

### 消息类型

| 来源 | 场景 |
|------|------|
| **审批通知** | 待办提醒、审批结果通知 |
| **CRM 通知** | 客户分配、跟进计划到期提醒 |
| **系统通知** | 公告推送、任务到期提醒 |
| **个人消息** | 用户间互发消息 |

### SSE 实时推送

站内消息基于 **Server-Sent Events (SSE)** 实现实时推送，用户无需刷新页面即可收到新消息：

- 浏览器通过 `GET /oa/messages/stream` 建立长连接
- 新消息到达时服务端主动推送，前端即时显示未读数
- 连接断开后自动重连，保证消息不丢失

## 自定义表单

自定义表单是 OA 的灵活扩展机制，允许管理员不写代码就创建新的业务表单（如用印申请、物资领用、活动报名等）。

### 表单模板

| 配置项 | 说明 |
|--------|------|
| **表单 Key** | 唯一标识，用于关联审批流 |
| **字段配置** | JSON Schema 定义表单字段（文本/数字/日期/下拉/附件等） |
| **分类** | 业务表单 / 非业务表单 |
| **启用/停用** | 控制员工端是否可见 |
| **审批关联** | 表单 Key 可在审批中心配置对应的审批流 |

### 表单数据

- 员工在「工作台 → 表单」中填写已启用的表单
- 提交后走审批流程
- 管理员可查看所有提交记录

## 与其他模块的联动

| 联动模块 | 联动场景 |
|---------|---------|
| [审批中心](./approval) | 报销/出差/借款/会议预订/表单全部接入审批流 |
| [CRM](./crm) | 跟进计划到期自动生成站内消息提醒 |
| [HRM](./hrm) | 请假审批结果联动考勤汇总 |
| [财务管理](./finance) | 报销打款可生成财务凭证 |
| [系统管理](./system) | 消息推送配置、审批人定义 |
