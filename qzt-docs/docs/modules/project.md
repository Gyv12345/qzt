# 项目管理

项目管理模块提供轻量级的项目协作能力，支持**项目立项、任务跟踪、进度管理**，并与 CRM 客户/合同打通，适合交付型团队管理从签约到交付的全过程。

## 核心概念

```
┌──────────────┐    包含多个    ┌──────────────┐
│   项目       │ ────────────▶ │   任务       │
│  Project     │               │   Task       │
└──────┬───────┘               └──────────────┘
       │
       ├── 关联客户（CRM Customer）
       ├── 关联合同（CRM Contract）
       ├── 项目经理（负责人）
       └── 团队成员
```

## 项目管理

| 字段 | 说明 |
|------|------|
| **项目编号** | 自动生成，唯一标识 |
| **项目名称** | 项目主标题 |
| **客户** | 关联 [CRM](./crm) 客户，打通交付链路 |
| **合同** | 可关联 CRM 合同 |
| **项目经理** | 项目负责人 |
| **团队成员** | 多人参与，逗号分隔 |
| **优先级** | 低 / 正常 / 高 / 紧急 |
| **项目状态** | 立项中 → 进行中 → （暂停）→ 已完成 / 已取消 |
| **进度** | 0-100%，手动更新或按任务完成率自动计算 |
| **标签** | 自定义标签，便于分类筛选 |
| **日期** | 计划开始日期 / 计划结束日期 |

### 项目状态流转

```
立项中 → 进行中 → 已完成
  │         │
  │         ├── 暂停（可恢复）
  │         └── 已取消
  └── 已取消
```

## 任务管理

任务是项目的执行单元，采用看板风格的状态管理。

| 任务属性 | 说明 |
|---------|------|
| **标题** | 任务名称 |
| **负责人** | 指派给具体团队成员 |
| **状态** | 待办 / 进行中 / 已完成 / 已取消 |
| **优先级** | 低 / 正常 / 高 / 紧急 |
| **排序** | 支持拖拽排序，适配看板视图 |
| **截止日期** | 任务 deadline |
| **完成时间** | 状态变为「已完成」时自动记录 |

### 任务状态流转

任务状态通过独立的 `PUT /tasks/:id/status` 接口变更，适配前端看板拖拽交互：

```
待办 → 进行中 → 已完成
  │       │
  └───────┴── 已取消
```

## 与其他模块的联动

| 联动模块 | 联动场景 |
|---------|---------|
| [CRM](./crm) | 项目关联客户与合同，形成「销售 → 交付」闭环 |
| [审批中心](./approval) | 项目立项可走审批流 |
| [OA](./oa) | 项目里程碑可创建日程提醒 |
