# PSI 进销存

PSI（Purchase / Sales / Inventory）是企智通平台的进销存模块，覆盖**采购**、**销售**、**库存**三大业务环节，并集成**供应商**、**仓库**、**产品**等基础数据。模块与 CRM、审批中心、财务管理深度联动：销售单可关联合同，采购销售单可走审批流，库存变动自动生成财务凭证，实现「业务流 → 数据流 → 资金流」的三流合一。

## 业务全景

```
┌──────────┐  采购入库  ┌──────────┐  销售出库  ┌──────────┐
│  供应商   │ ────────▶ │   仓库    │ ────────▶ │   客户    │
│ Supplier │            │ Warehouse │           │ Customer │
└──────────┘ ◀──────── └──────────┘ ◀──────── └──────────┘
              采购退货              销售退货
```

| 业务方向 | 单据类型 | 库存影响 |
|---------|---------|---------|
| 采购 | 采购单 | 入库（+） |
| 采购退货 | 采购退货单 | 出库（-） |
| 销售 | 销售单 | 出库（-） |
| 销售退货 | 销售退货单 | 入库（+） |
| 其他入库 | 其他入库单 | 入库（+） |
| 其他出库 | 其他出库单 | 出库（-） |

## 采购管理

### 采购单

采购单记录向供应商采购商品的全过程：

- **供应商**：关联赛基础数据中的供应商档案；
- **采购明细**：产品、规格、数量、单价、税率、金额；
- **仓库**：指定到货仓库；
- **采购员**：关联员工，用于绩效统计；
- **状态流转**：草稿 → 待审批 → 已审核 → 已入库 → 已完成；
- **审批集成**：大额采购可配置走审批流（详见 [审批中心](./approval)）；
- **自动编号**：如 `CG20260806001`。

### 采购退货

采购入库后若发现质量问题，可发起采购退货：

- 关联原采购单，自动带入明细；
- 选择退货产品、数量、原因；
- 退货审核通过后自动减少库存；
- 退货可触发供应商应付账款冲减（联动财务）。

## 销售管理

### 销售单

销售单记录向客户销售商品的全过程，是收入确认和出库的依据：

- **客户**：关联 CRM 客户档案；
- **关联合同**：销售单可关联 CRM 合同，自动带入合同产品明细，避免重复录入；
- **销售明细**：产品、规格、数量、单价、折扣、税率、金额；
- **仓库**：指定发货仓库；
- **销售员**：关联员工，用于销售业绩统计；
- **状态流转**：草稿 → 待审批 → 已审核 → 已出库 → 已完成；
- **审批集成**：折扣销售、大额销售可走审批流；
- **自动编号**：如 `XS20260806001`。

:::tip 关联合同
销售单与 CRM 合同的关联是 PSI 与 CRM 联动的核心：合同签订后，其产品明细可直接生成销售单草稿，销售出库后合同回款进度自动更新，形成完整的「合同 → 销售 → 出库 → 回款」闭环。
:::

### 销售退货

客户退货通过销售退货单处理：

- 关联原销售单，自动带入明细；
- 选择退货产品、数量、原因；
- 退货审核通过后自动增加库存；
- 退货可触发客户应收账款冲减（联动财务）。

## 库存管理

### 实时结余

系统实时维护每个仓库中每个产品的库存结余：

- **库存维度**：仓库 × 产品（× 批次，可选）；
- **可用库存** = 实际库存 - 锁定库存（如已审核未出库的销售单）；
- 库存预警：低于安全库存自动提醒；
- 多仓库支持：每个仓库独立核算结余。

### 收发明细

每一次库存变动都会生成一条收发明细，形成完整的库存流水：

| 字段 | 说明 |
|------|------|
| 单据类型 | 采购入库 / 销售出库 / 退货 / 其他 |
| 关联单据 | 来源单据编号 |
| 产品 | 变动产品 |
| 数量 | +入库 / -出库 |
| 仓库 | 变动仓库 |
| 操作人 | 经办人 |
| 操作时间 | 变动时间 |

收发明细不可篡改，是库存审计的依据。

### 其他出入库

除采购销售外的库存变动通过「其他出入库」单据处理：

- **其他入库**：盘盈、赠送入库、调拨入库、期初建账；
- **其他出库**：盘亏、损耗、领用、调拨出库；
- 每笔其他出入库需填写**变动原因**，便于追溯；
- 其他出入库同样生成收发明细，影响实时结余。

## 基础数据

### 供应商

供应商档案是采购管理的基础：

- 字段：名称、编码、联系人、联系电话、地址、银行账户、税率、备注；
- 供应商与 CRM 客户共用基础信息架构，但独立维护；
- 支持供应商分级（战略 / 重点 / 普通）；
- 支持供应商禁用（停止合作后不再可选）。

### 仓库

仓库是库存核算的空间维度：

- 支持多仓库：总仓、分仓、门店仓、虚拟仓；
- 仓库编码、名称、地址、负责人；
- 仓库可启用/停用；
- 仓库间支持**调拨**业务（调出仓出库 + 调入仓入库）。

### 产品（共用 CRM 产品）

产品档案是进销存与 CRM 的**共用主数据**：

- 产品信息：名称、编码、规格、单位、条码、分类；
- 价格信息：采购参考价、销售指导价、最低售价；
- 库存信息：安全库存、计量单位；
- 产品图片、详细描述；
- 产品可同时用于 CRM 报价、PSI 采购销售，保证全平台产品口径一致。

## 审批集成

PSI 的关键业务单据均可配置审批流：

| 单据 | 典型审批场景 |
|------|------------|
| 采购单 | 金额 > 5万 需采购总监审批 |
| 销售单 | 折扣 < 8折 需销售总监审批 |
| 采购退货 | 需质检、采购、财务多方确认 |
| 销售退货 | 需销售、客服、财务确认 |
| 其他出库 | 非常规出库需审批 |

审批配置在「审批中心」统一管理，审批通过后单据自动流转到下一状态（如待审核 → 已审核）。
