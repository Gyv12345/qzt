# 系统管理

系统管理是企智通平台的基础设施模块，为其他所有业务模块提供用户、权限、菜单、配置、日志等底层支撑。本模块采用「**后端驱动前端**」的架构设计：菜单、权限、字典、编号规则等均由后端统一管理，前端根据后端配置动态渲染路由与界面，确保多端（PC 后台、移动端）一致且安全。

## 核心能力一览

| 能力 | 说明 |
|------|------|
| 用户管理 | 左树右表，按部门组织用户 |
| 角色管理 | RBAC 权限 + 数据权限 |
| 菜单管理 | 后端菜单驱动前端路由 |
| 字典管理 | 全局枚举值维护 |
| 系统配置 | 热配置，无需重启 |
| 操作日志 | 全量操作审计 |
| 登录日志 | 登录记录与安全分析 |
| 业务编号设置 | 可配置前缀与格式 |
| 数据重置 | 一键清理业务数据 |
| 存储配置 | OSS / 本地切换 |
| 站点信息 | Logo、备案、SEO |

## 用户管理

用户（User）是系统的登录主体，与 HRM 员工（Employee）关联。用户管理采用经典的「**左树右表**」布局：左侧为部门树，右侧为该部门下的用户列表。

### 界面布局

```
┌─────────────┬───────────────────────────────────────┐
│  部门树      │  用户列表（可按部门过滤）               │
│             │                                       │
│  ├ 总裁办    │  ┌──────────────────────────────────┐ │
│  ├ 销售中心  │  │ 用户名 │ 部门 │ 角色 │ 状态 │ 操作│ │
│  │ ├ 销售一部│  │        │      │      │      │     │ │
│  │ └ 销售二部│  └──────────────────────────────────┘ │
│  ├ 研发中心  │                                       │
│  └ 财务部    │                                       │
└─────────────┴───────────────────────────────────────┘
```

### 部门过滤

- 点击左侧部门节点，右侧用户列表自动过滤为该部门（含子部门）的用户；
- 支持「仅本部门」「本部门及子部门」两种过滤模式；
- 支持按用户名、手机号、状态搜索。

### 用户字段

| 字段 | 说明 |
|------|------|
| 用户名 | 登录账号，唯一 |
| 姓名 | 显示名称 |
| 部门 | 关联组织架构 |
| 岗位 | 关联 HRM 岗位 |
| 角色 | 决定功能权限 |
| 数据权限范围 | 决定数据可见范围 |
| 状态 | 启用 / 禁用 |
| 联系方式 | 手机、邮箱 |
| 关联员工 | 与 HRM 员工记录关联 |

## 角色管理

角色（Role）是权限分配的载体，采用 **RBAC（Role-Based Access Control）** 模型：用户通过角色获得权限，而非直接分配权限，简化权限管理。

### 功能权限（RBAC）

功能权限控制「**能做什么**」，粒度到按钮级别：

- **菜单权限**：角色可见哪些菜单；
- **操作权限**：在菜单内可执行哪些操作（查看、新增、编辑、删除、导出、审批）；
- **按钮权限**：具体按钮的显示与隐藏（如「重置数据」按钮仅超管可见）。

权限通过「菜单管理」中的权限标识（permission key）定义，角色在授权时勾选。

### 数据权限

数据权限控制「**能看哪些数据**」，比功能权限更精细，企智通支持以下数据范围：

| 数据范围 | 说明 | 示例 |
|---------|------|------|
| **全部数据** | 可看所有数据 | 总经理查看全公司客户 |
| **本部门数据** | 仅看本部门数据 | 销售经理查看本部门客户 |
| **本部门及子部门** | 含下属部门 | 销售总监查看销售中心所有客户 |
| **仅本人数据** | 仅看自己负责的 | 销售员只看自己的客户 |
| **自定义部门** | 指定可见部门 | 跨部门协作场景 |

数据权限可按模块独立配置（CRM 客户、PSI 单据、财务凭证分别设置不同范围）。

## 菜单管理

企智通采用「**后端菜单驱动前端路由**」的架构，菜单不仅是界面元素，更是路由与权限的源头。

### 后端驱动前端

```
┌──────────────┐   加载菜单 API    ┌──────────────┐
│  前端应用     │ ◀──────────────  │  后端服务     │
│  (Admin/Mobile)│                  │              │
└──────┬───────┘                  └──────┬───────┘
       │                                 │
       │  动态生成路由                    │  菜单数据源
       │  动态渲染侧边栏                  │  (数据库)
       ▼                                 ▼
┌──────────────┐                  ┌──────────────┐
│  用户看到的   │                  │  sys_menu 表  │
│  界面与功能    │                  │              │
└──────────────┘                  └──────────────┘
```

**优势**：

- 新增功能只需在后端配置菜单，前端自动适配，无需重新发布前端；
- 不同角色看到的菜单不同，实现千人千面；
- PC 后台与移动端共用一套菜单定义，保证一致性。

### 菜单字段

| 字段 | 说明 |
|------|------|
| 菜单名称 | 显示文本 |
| 菜单类型 | 目录 / 菜单 / 按钮 |
| 路由路径 | 前端路由地址 |
| 组件路径 | 前端组件文件路径 |
| 权限标识 | permission key，如 `crm:customer:add` |
| 图标 | 菜单图标 |
| 排序 | 同级菜单排序 |
| 是否缓存 | 前端是否 keep-alive |
| 可见性 | 是否在侧边栏显示（隐藏菜单仍可访问） |

## 字典管理

字典（Dictionary）管理全局的枚举值，避免硬编码，统一维护下拉选项。

### 字典结构

- **字典类型**：如「客户来源」「客户级别」「行业类型」「跟进方式」；
- **字典项**：每个类型下的具体选项，包含字典值、字典标签、排序、样式（颜色标签）。

### 应用场景

- CRM 客户来源：转介绍、广告、官网、展会、其他；
- CRM 客户级别：A（重点）、B（一般）、C（普通）；
- PSI 单据状态：草稿、待审、已审、已完成；
- HRM 请假类型：事假、病假、年假、调休。

字典修改后，所有引用该字典的下拉框自动更新，无需改代码。

## 系统配置

系统配置提供**热配置**能力，修改后立即生效，无需重启服务。

### 配置分类

| 分类 | 配置项示例 |
|------|----------|
| **CRM** | 公海回收天数、领取上限、成交概率 |
| **PSI** | 安全库存预警开关、负库存控制 |
| **审批** | 超时催办时间、默认抄送人 |
| **通知** | 站内信、企业微信开关 |
| **存储** | OSS / 本地切换、上传大小限制 |

配置项支持文本、数字、开关、JSON 等多种类型，前端根据类型自动渲染表单。

## 操作日志

操作日志记录用户在系统中的所有关键操作，满足安全审计与合规要求。

### 记录内容

| 字段 | 说明 |
|------|------|
| 操作人 | 用户名 |
| 操作模块 | CRM / PSI / 系统 |
| 操作类型 | 新增 / 修改 / 删除 / 导出 / 登录 |
| 操作对象 | 具体记录的 ID 与名称 |
| 操作内容 | 详细变更（前值 → 后值） |
| 请求参数 | API 请求参数 |
| 操作时间 | 精确到毫秒 |
| 操作 IP | 客户端 IP |
| 耗时 | 接口响应耗时 |

操作日志不可删除，保留期限可在配置中设置（默认 1 年）。

## 登录日志

登录日志记录所有用户的登录行为，用于安全分析：

- 登录时间、登录 IP、登录地点（IP 解析）；
- 登录方式：账号密码、企业微信扫码、Token 刷新；
- 登录结果：成功 / 失败（密码错误、账号禁用）；
- 异常检测：异地登录、非工作时间登录、频繁失败。

## 业务编号设置

所有业务对象的自动编号规则在此统一配置（详见各业务模块）：

| 配置项 | 说明 |
|--------|------|
| 业务对象 | 客户 / 线索 / 商机 / 合同 / 回款 / 凭证等 |
| 前缀 | 如 KH、HT、PZ |
| 日期格式 | yyyyMMdd / yyyyMM / yyyy |
| 流水位数 | 3 ~ 6 位 |
| 示例预览 | 实时预览生成效果 |

编号规则修改后对新创建的对象生效，历史对象编号不变。

## 数据重置

数据重置提供**一键清理业务数据**的能力，主要用于测试环境的数据清理或系统初始化。

:::danger 高危操作
数据重置会**永久删除**选定模块的所有业务数据（客户、合同、单据等），且不可恢复。操作前系统会强制二次确认，并要求输入超级管理员密码。生产环境建议关闭此功能或限制为超管专用。
:::

### 可重置范围

- 仅重置 CRM 数据（客户、线索、商机、合同、回款）；
- 仅重置 PSI 数据（采购、销售、库存）；
- 仅重置财务数据（凭证、发票）；
- 全部业务数据重置（保留系统配置、用户、角色）。

重置不会删除用户、角色、菜单、字典等基础配置数据。

## 存储配置

存储配置管理文件上传的存储驱动，支持 **OSS（阿里云对象存储）** 与 **本地存储** 两种模式，可随时切换。

| 配置项 | OSS 模式 | 本地模式 |
|--------|---------|---------|
| Endpoint | oss-cn-hangzhou.aliyuncs.com | - |
| Bucket | your-bucket | - |
| AccessKey | AK / SK（加密） | - |
| 存储路径 | OSS 路径 | 服务器本地目录 |
| 访问域名 | OSS 域名 / CDN | 资源访问域名 |
| 单文件大小上限 | 可配置 | 可配置 |

切换存储模式后，新上传的文件按新配置存储，历史文件路径不变。提供「连接测试」功能，配置后可一键验证 OSS 连通性。

| 配置项 | 说明 |

| 企业名称 | 如「河南爱编程网络科技有限公司」 |
| 品牌标语 | Slogan |
| Logo | 企业 Logo（支持深色/浅色） |
| Favicon | 浏览器图标 |
| 联系电话 | 客服电话 |
| 联系邮箱 | 官方邮箱 |
| 公司地址 | 办公地址 |
| 工作时间 | 服务时间 |
| ICP 备案号 | 工信部备案 |
| 公安备案号 | 公安备案 |
| SEO 关键词 | 搜索引擎优化 |
| 版权声明 | 页脚版权 |

站点信息修改后，Admin 与 CMS 站点同步生效。
